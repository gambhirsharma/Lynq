# Lynq brand kit
Start with **BRAND-GUIDE.md**.

- `logos/orbital-link/`: primary mark (icon, horizontal, stacked, product; dark/light/black/white)
- `logos/pulse-path/`: product and live-dashboard mark (+ animated SVG)
- `favicon/`: SVG + PNG favicons for both marks
- `tokens/lynq-tokens.css`: colours, fonts, spacing and radii as CSS variables

Fonts: Urbanist (Google Fonts), Satoshi (Fontshare), JetBrains Mono (Google Fonts). All are free.
